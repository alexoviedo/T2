USB2BLE iPhone Compatibility Check

A Safari Gamepad API smoke page for the USB2BLE Generic BLE HID path. It does not use Web Serial and does not prove broad iOS or game compatibility by itself.

Steps

  1. Pair USB2BLE Gamepad in iPhone Bluetooth settings.
  2. Open this page in Safari.
  3. Tap Start/Arm.
  4. Move throttle, rudder, and toe brakes while this page is open.
  5. Tap Copy Evidence JSON or Download Evidence JSON.
