# USB2BLE v0.1.0-alpha

USB2BLE v0.1.0-alpha is an evidence-backed public alpha for an ESP32-S3 USB HID
to Bluetooth LE gamepad bridge, with a Web Serial configurator and a practical
Thrustmaster Flight Pack Generic demo path.

This is an alpha release. It is intended for developers, makers, and early
hardware testers who are comfortable with experimental firmware and scoped
compatibility claims.

## What Works

- ESP32-S3 target build, firmware packaging, GitHub Release artifact publishing,
  and GitHub Pages deployment.
- USB HID attach/detach identity, descriptor capture, raw report capture, HID
  summary, and normalized input diagnostics.
- Practical RJ12 Flight Pack topology:
  - T.16000M stick over USB,
  - TWCS throttle over USB,
  - TFRP pedals through the TWCS RJ12 port,
  - HooToo SHUTTLE HT-UC001 powered hub.
- Runtime config import/save/load across an actual board reset.
- Chrome Web Serial configurator smoke for config/status/schema/catalog load,
  Flight Pack Generic import, save, load, and `START_CONFIGURED`.
- Refined Generic Flight Pack target-side mapping and report encoding.
- Refined Generic browser Gamepad API axis exposure in Chrome.
- Refined Generic 300-second live bridge soak in Chrome.
- Narrow self-hosted browser game/app smoke with the refined Generic profile.
- Xbox BLE identity/report publishing slice with macOS pairing/input witness.

## Quick Start

- Repository: <https://github.com/alexoviedo/T2>
- Web configurator and firmware flasher: <https://alexoviedo.github.io/T2/>
- Evidence index: <https://github.com/alexoviedo/T2/blob/v0.1.0-alpha/docs/EVIDENCE_INDEX.md>
- Release checklist: <https://github.com/alexoviedo/T2/blob/v0.1.0-alpha/docs/RELEASE_CHECKLIST.md>
- Public claims guide: <https://github.com/alexoviedo/T2/blob/v0.1.0-alpha/docs/PUBLIC_CLAIMS.md>

Local no-hardware validation:

```bash
./scripts/validate_no_hardware.sh
./scripts/check_target_build.sh
```

Flash locally:

```bash
./scripts/build.sh
./scripts/flash.sh --port <PORT>
```

Configure the refined Generic Flight Pack profile:

```bash
python3 tools/configure_board.py --port <PORT> preset flight-pack-generic
python3 tools/serial_command.py --port <PORT> GET_CONFIG_STATUS START_CONFIGURED GET_BRIDGE_STATUS
```

## Known Limitations

This release does not claim:

- external/native game compatibility,
- iPhone compatibility,
- Xbox host-visible refined Flight Pack mapping,
- BLE bond persistence or reconnect hardening,
- final product-quality deadzone/calibration feel,
- broad host/browser support,
- simultaneous three-separate-USB Flight Pack streaming.

The self-hosted browser game/app smoke is a narrow browser app data point. It is
not broad game compatibility and not native app compatibility.

## Safety

USB2BLE is experimental firmware. BLE HID behavior can vary by host OS, browser,
Bluetooth cache state, game engine, and controller profile. Do not use it where
unexpected input, disconnects, or firmware faults could create safety risk.
