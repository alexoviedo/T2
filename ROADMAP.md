# Roadmap

This roadmap is intentionally evidence-driven. Items move from planned to proven
only when checked-in evidence supports them.

## Near Term

- External browser or native app/game compatibility witness for the refined
  Generic Flight Pack profile.
- Xbox host-visible refined Flight Pack mapping witness.
- BLE reconnect and bond persistence hardening.
- Product-quality deadzone and calibration tuning.
- Three-separate-USB Flight Pack streaming investigation.

## Mid Term

- Broader host compatibility matrix.
- Repeatable app/game compatibility matrix.
- Web configurator UX improvements.
- Better runtime config editing, validation, and export/import ergonomics.
- Shared witness-helper library for serial transcripts, artifacts, and summaries.

## Long Term

- Additional BLE controller personas.
- More HOTAS and gamepad hardware profiles.
- More robust HID descriptor/report normalization.
- Longer-duration soak and reconnect testing across hosts.
