# Code of Conduct

USB2BLE aims to be a respectful project for embedded developers, makers,
testers, and early adopters.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while still being precise about technical facts.
- Keep criticism focused on code, evidence, documentation, and reproducibility.
- Respect maintainers' time and the experimental state of the project.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks or sustained hostility.
- Publishing private information without consent.
- Pressuring maintainers to overclaim compatibility or safety.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; restrict
participation; or block users when needed to keep the project healthy.

If you need to report conduct concerns, use the repository's private contact or
security reporting path if available.
